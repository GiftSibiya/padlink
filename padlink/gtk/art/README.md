# Shipped controller artwork

SVGs placed here ship with padlink and are used on the Input tab:
`xbox.svg`, `playstation.svg`, `nintendo.svg`, or model-specific
`xbox360.svg`, `xboxone.svg`, `xboxseries.svg`, `ds4.svg`, `dualsense.svg`,
`switchpro.svg`. A user's own files in `~/.config/padlink/art/` take priority.

Start from the templates in `data/art-templates/` and check your file with
`padlink art check <file.svg>`. The full naming contract is in the main README
under "Controller artwork".
